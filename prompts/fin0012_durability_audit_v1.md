# Harmony FIN-0012 Alpha Durability Audit v1

Highest-priority follow-up after Alpha Autopsy v1.

Alpha Autopsy v1 found that FIN-0012 had strong raw OOS performance, low benchmark-factor R², and a high matched-placebo percentile, but its earlier fixed half-split showed strong first-half versus negative second-half behavior.

This audit must determine whether the apparently independent FIN-0012 edge is sufficiently persistent to justify a separate frozen validation descendant, without changing FIN-0012 itself.

## Hard integrity rules

1. FIN-0012 is immutable.
2. Do not change its signal, parameters, universe, weights, rebalance schedule, fees, slippage, funding, or liquidation.
3. No parameter search, universe search, direction search, or candidate mutation.
4. No data after 2025-10-31.
5. Preserve all pre-OOS observations required by the registered 60-day beta and 20-day momentum lookbacks.
6. Use only the verified harmony-binance-um-2021-01-2025-10-v4 cache.
7. Reproduce the accepted FIN-0012 result before issuing durability conclusions.
8. Any reproduction mismatch stops the audit.
9. This is a diagnostic/validation audit, not an optimization run.

## Required tests

### 1. Exact reproduction gate
Reconstruct FIN-0012 over 2021-01-01 through 2025-10-31 with OOS 2024-05-22 through 2025-10-31.

Verify cumulative return, CAGR, Sharpe, max drawdown, turnover, transaction costs, and funding PnL against the accepted persisted FIN-0012 result.

### 2. Fixed OOS temporal decomposition
Report the frozen strategy over:
- first chronological OOS half
- second chronological OOS half
- four equal chronological OOS quarters

For every segment report cumulative return, CAGR, Sharpe, Sortino, max drawdown, and observations.

### 3. Rolling durability
Use fixed 90-observation and 180-observation rolling windows.

Report rolling Sharpe, cumulative return, and max drawdown plus:
- median
- 25th/75th percentiles
- min/max
- fraction of windows with positive return
- fraction with positive Sharpe

These are fixed diagnostic windows, not tunable parameters.

### 4. Factor-residual durability
Use the same 60-observation rolling BTC + same-universe equal-weight attribution methodology as Alpha Autopsy v1.

Report full residual metrics and quarter-by-quarter residual metrics.

Do not describe residual returns as causal alpha.

### 5. Cost durability
Re-run the frozen strategy at exactly:
- 1.0x base costs
- 1.5x base costs
- 2.0x base costs

Report raw and residual metrics.

### 6. Timing concentration
Report OOS contribution by calendar year and quarter, including the fraction of total OOS profit generated by the best year and best quarter.

### 7. Final research status
Return exactly one:
- DURABILITY_SUPPORTED
- DURABILITY_MIXED
- DURABILITY_NOT_SUPPORTED

The status is descriptive research evidence only.
