# Harmony Deep Grind v1

Objective: maximize reliable information gain about potentially durable crypto research edges by running the strongest already-preregistered, frozen Harmony research protocols available in one bounded session.

Hard invariants:
- Never access or use data after 2025-10-31.
- Never mutate a candidate definition, parameter, universe, direction, rebalance rule, cost model, or selection rule.
- Never perform post-hoc parameter or universe search.
- Never convert diagnostics into promotion decisions.
- Preserve exact provenance and observed failures.
- A failed or inconclusive subprotocol is evidence, not permission to weaken its gate.

Session components:
1. FIN-0012 reproducibility-first durability audit.
2. FIN-0012 / FIN-0024 benchmark-factor alpha autopsy with deterministic placebo tests.
3. HARMONY-CAMPAIGN-002 four-candidate funding-carry temporal robustness and cost stress.
4. HARMONY-DEEP-DISCOVERY-BATCH-007 low-volatility cross-sectional OOS validation.

Synthesis:
- Reconcile all subprotocol outputs into one session-level evidence map.
- Separate raw performance, benchmark exposure, residual performance, temporal durability, cost durability, and placebo evidence.
- Look for contradictions and implementation/accounting discrepancies before drawing conclusions.
- Identify which research families are genuinely differentiated versus largely redundant.
- Rank remaining uncertainties by expected information value, not excitement.
- Prefer the smallest next experiment that can most reduce the most consequential uncertainty.
- Do not create a descendant candidate during the grind.

Execution:
- Run every component even when another component fails, where safe and computationally practical.
- Persist stdout/stderr and exact return codes for every component.
- Produce a cryptographic manifest of all generated evidence.
- Produce explicit PASS / PARTIAL / FAIL status for each component and one session-level status.
